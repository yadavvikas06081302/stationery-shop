# Ajay Stationery Shop

A responsive stationery shopping website built with HTML, CSS and JavaScript.

## Features
- Product categories
- Product search
- Add to cart
- Quantity controls
- Automatic cart total
- Checkout/order form
- LocalStorage cart persistence
- Responsive design for mobile and desktop
- Works directly in Google Chrome
- GitHub Pages compatible

## Run on Chrome
1. Extract the ZIP file.
2. Open the `Stationery-Shop` folder.
3. Double-click `index.html`.
4. It will open in Google Chrome.

## GitHub Pages
1. Create a new GitHub repository, for example `Stationery-Shop`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Important for a real business
This project is a complete browser-side shop UI. To accept genuine online orders/payments, connect a backend/database and a payment gateway such as Razorpay/Stripe, and add real product inventory, delivery settings and order management.
